# Left 4 Dead 2 Autosplitter

A Left 4 Dead 2 Autosplitter specifically for the v2.0.0.0 version of the game.

- This autosplitter is not complete and lacking some features from the original autosplitter from LiveSplit
- Individual Level runs should work fine.
- Main Campaign runs currently have splitting issues when used with a vote cycler
