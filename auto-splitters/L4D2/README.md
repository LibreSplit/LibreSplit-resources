# Left 4 Dead 2 Autosplitter

A Left 4 Dead 2 Autosplitter specifically for the v2.0.0.0 version of the game.

- **This relies on Game Instructor being enabled!**
- This autosplitter is not complete and lacks some features from the original autosplitter from LiveSplit
- Individual Level and Main Campaign runs should work fine.
